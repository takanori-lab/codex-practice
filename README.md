# 次の休み、どこ行く？

日本語の旅行先診断サイトです。日数、予算、旅行の目的、気候、旅行ペースを選ぶと、国内外の旅行先データから相性の高いおすすめを3件表示します。

## 主な機能

- 日数・予算・目的・気候・旅行ペースによる旅行先診断
- 国内外20か所の旅行先データを内蔵
- おすすめ順の上位3件表示
- 相性スコア、おすすめ理由、予算目安、移動時間、モデルプラン、グルメ情報の表示
- 診断中の飛行機・電車アニメーション
- 気に入った旅行先をlocalStorageへお気に入り保存
- 「もう一度診断」ボタンで再診断
- スマートフォンとPCに対応したレスポンシブデザイン

## 使い方

1. `index.html` をブラウザで開きます。
2. 「診断をはじめる」から条件を選択します。
3. 「おすすめを見る」を押すと、相性の高い旅先が3件表示されます。
4. 気になる旅先は「お気に入りに保存」ボタンで保存できます。
5. 再診断したい場合は「もう一度診断」を押してください。

## ファイル構成

- `index.html`：ページ構造
- `styles.css`：旅行雑誌風の爽やかなデザインとレスポンシブ対応
- `script.js`：診断ロジック、旅行先データ、お気に入り保存処理

## 技術メモ

外部APIや有料サービスは使用していません。お気に入りはブラウザのlocalStorageに保存されます。
